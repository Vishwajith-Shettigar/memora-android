## 🔧 Setup

1. **Create a `secrets.properties` file** in the **root directory** of your project.

2. **Add the following keys** (replace with your actual values):

   ```properties
   MAPS_API_KEY=your_google_maps_api_key
   MAP_BOX_API_KEY=your_mapbox_api_key
   MAP_BOX_PUBLIC_ACCESS_TOKEN=your_mapbox_public_token
   MAPBOX_STYLE_URI_DAY=your_mapbox_day_style_uri
   MAPBOX_STYLE_URI_NIGHT=your_mapbox_night_style_uri
   STRIPE_SERVER_URL=https://your-stripe-server-url.com/payment-sheet
   SERVER_URL=https://your-server-url.com
